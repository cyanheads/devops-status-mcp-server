# 0.11.2 — 2026-11-16

## Added

- **`incidentio` backend** ([#98](https://github.com/cyanheads/devops-status-mcp-server/issues/98)) — `fly-io`, `planetscale`, `supabase`, `brevo`, `clerk`, `openai`, `elevenlabs`, and `cohere` read their page's own feed, with every component and incident, in place of the compatible API's 25. History reaches back 90 days, and `since` reads the page's quarterly list up to 24 months. `api_type` may now be `incidentio`.
- **`statuspage_not_found`** error reason ([#103](https://github.com/cyanheads/devops-status-mcp-server/issues/103)) — a raw URL that serves no Statuspage API fails as non-retryable, naming the registry slug where the host belongs to one. `statuspage_unavailable` still marks transient failures.

## Changed

- **Concurrent reads of one URL** share one request ([#100](https://github.com/cyanheads/devops-status-mcp-server/issues/100)); a failed request caches nothing.
- **Empty `active` or `resolved` results** on a call that read no incident record suggest `scheduled` only for vendors that publish maintenance windows ([#101](https://github.com/cyanheads/devops-status-mcp-server/issues/101)).
- **Empty-result hints** respect `since` and `until` and name only filters the vendor offers.
- **Raw vendor URLs** are read and echoed at origin and path; userinfo, query, and fragment are dropped.
- **`filter: "scheduled"`** on a Statuspage page with no maintenance feed returns empty with a `notice`.
- **`since` history reads** stop at one 30-second limit across all pages they fetch.
- **Completion logs** name each unavailable vendor and its reason ([#104](https://github.com/cyanheads/devops-status-mcp-server/issues/104)).
- **`devops-status-guide` skill** `metadata.version` 1.1 → 1.2.

## Fixed

- **Incidents and updates with no readable timestamp** sort as the oldest on the incident.io, Datadog, Firehydrant, Azure, Azure DevOps, and Google Cloud adapters and in `devops_get_incidents`, so `latest_update` in `devops_status_check` and `devops_watch_stack` is the newest dated update.
- **incident.io pages whose stated start date can't be read** get the plain default-window `notice`.
