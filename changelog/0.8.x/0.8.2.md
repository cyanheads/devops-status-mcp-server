# 0.8.2 — 2026-09-20

## Added

- **CONTRIBUTING.md and CODE_OF_CONDUCT.md** — routes a bug report to this repo or [mcp-ts-core](https://github.com/cyanheads/mcp-ts-core) depending on which layer broke, links the private security-advisory form, and assigns new issues to `cyanheads`.

## Changed

- **`createApp({ sessionMode: 'stateless' })`** declares the HTTP session posture in source ([#376](https://github.com/cyanheads/mcp-ts-core/issues/376)) — no tool here calls `ctx.requestInput`, and `devops_watch_stack` persists through tenant-scoped `ctx.state`, not the session store, so nothing needs a session to survive between calls. `MCP_SESSION_MODE` still overrides when set to a meaningful value.
- **A tool-argument rejection's error text now closes with `(reason invalid_arguments · not retryable)` and a schema-derived `Recovery:` hint** ([#445](https://github.com/cyanheads/mcp-ts-core/issues/445), [#458](https://github.com/cyanheads/mcp-ts-core/issues/458)); a required field omitted from an enum (`filter`, `mode`) now reports as missing rather than as a wrong choice ([#378](https://github.com/cyanheads/mcp-ts-core/issues/378)).
- **A cancelled call classifies `RequestCancelled` (-32011)** instead of a generic internal error ([#421](https://github.com/cyanheads/mcp-ts-core/issues/421)); a 3xx from a vendor status API maps to `InvalidRequest` instead of `InternalError` ([#460](https://github.com/cyanheads/mcp-ts-core/issues/460)), and an upstream 500 now retries like the rest of the 5xx range.
- **`devops_get_incidents`'s upstream-timeout entry is marked `thrownBy: 'service'`** ([#462](https://github.com/cyanheads/mcp-ts-core/issues/462)), matching where it's actually raised in the shared cached-fetch helper — lint-only metadata; the thrown error is unchanged.
- **Skills move from `skills/` to `framework-skills/`** ([#428](https://github.com/cyanheads/mcp-ts-core/issues/428)) — Claude Code and Codex auto-load a plugin's root `skills/`, so shipping `.claude-plugin/`/`.codex-plugin/` handed these development skills to every installing agent.
- **`manifest.json` forwards `DEVOPS_STATUS_ALLOW_PRIVATE_TARGETS` and `DEVOPS_STATUS_DISABLE_ACTIVE_PROBES` into `mcp_config.env`** — a Claude Desktop bundle install previously never saw either option.
